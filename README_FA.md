# AZN Flight Radar — نسخه اولیه

این پروژه یک اپ اندرویدی Cordova با نقشه Leaflet و داده زنده ADSB.lol است.

## ساخت APK با GitHub Actions
1. فایل ZIP را استخراج کنید.
2. همه محتویات پوشه را در یک مخزن جدید GitHub با نام `azn-flight-radar` بارگذاری کنید.
3. از زبانه Actions، گردش‌کار `Build AZN Flight Radar APK` را اجرا کنید.
4. پس از موفقیت، از بخش Artifacts فایل APK را دریافت کنید.

## محدودیت‌ها
- داده از API عمومی ADSB.lol است. محدودیت فعلی بدون کلید: 500 درخواست در روز برای هر IP؛ برنامه برای کاهش مصرف، هر 90 ثانیه به‌روزرسانی می‌کند.
- این نسخه هواپیماهای قابل مشاهده در شعاع اطراف مرکز نقشه را نمایش می‌دهد، نه تمام پروازهای جهان در یک درخواست.
- پوشش ADS-B در مناطق مختلف یکسان نیست. اطلاعات مبدأ/مقصد و تاریخچه کامل در این نسخه تضمین نمی‌شود.
- داده تحت مجوز ODbL 1.0 است؛ انتساب منبع در برنامه درج شده است.
- نقشه و کتابخانه Leaflet برای بارگذاری به اینترنت نیاز دارند.
