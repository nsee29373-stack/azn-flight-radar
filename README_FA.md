# AZN Flight Radar — نسخه پایه اشتراک

## مدل تجاری تنظیم‌شده
- دوره آزمایشی: ۳ روز
- روزانه: ۱ دلار
- ماهانه: ۵ دلار
- سه‌ماهه: ۱۲ دلار
- سالانه: ۳۹ دلار

## فایل‌ها
- `www/index.html`: نقشه رادار
- `www/subscription.js`: ورود، ثبت‌نام، بررسی دسترسی و صفحه طرح‌ها
- `www/config.js`: آدرس پروژه Supabase و کلید عمومی anon
- `supabase/schema.sql`: جداول طرح‌ها، اشتراک، سفارش پرداخت، RLS و شروع آزمایشی ۳ روزه
- `.github/workflows/build.yml`: ساخت APK با GitHub Actions

## راه‌اندازی Supabase
1. یک پروژه Supabase بساز.
2. SQL فایل `supabase/schema.sql` را در SQL Editor اجرا کن.
3. URL و anon key پروژه را در `www/config.js` وارد کن.
4. کلید `service_role` را هرگز در برنامه اندروید قرار نده.
5. پوشه‌ها را در GitHub بارگذاری و workflow را اجرا کن.

## وضعیت پرداخت
پرداخت واقعی هنوز عمداً غیرفعال است. برای اتصال امن، باید کشور دریافت‌کننده وجه و درگاه سازگار مشخص شود. فعال‌سازی اشتراک پولی فقط پس از تأیید تراکنش در وب‌هوک سمت سرور انجام می‌شود؛ برنامه به‌تنهایی نباید اشتراک را فعال کند.

## نکات مهم امنیتی و هزینه
- کلید Supabase service_role فقط در سرور/Edge Function و Secrets نگهداری شود.
- طرح رایگان Supabase محدودیت مصرف دارد؛ رشد کاربران ممکن است نیازمند هزینه شود.
- سرویس ADSB.lol و نقشه عمومی نیز محدودیت و شرایط استفاده دارند.
- قیمت‌ها فعلاً بر مبنای USD در دیتابیس ثبت می‌شوند؛ ارز و درگاه نهایی با توجه به کشور انتخاب می‌شوند.
